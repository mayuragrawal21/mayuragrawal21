## 🔬 Current Project: [EchoForge](https://github.com/thrive-centre/EchoForge)

EchoForge is an open-source Python library for echocardiographic view classification, segmentation, and phase detection. Designed for clinical, educational, and research workflows, it integrates pretrained models and benchmarked datasets for rapid AI deployment in cardiology.
